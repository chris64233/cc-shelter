# cc-shelter

管理家庭成员、床位资源和入住安排。

## 主要业务规则

- **整体入住**：家庭全部成员必须安排到同一安置点的同一房间，不允许拆分家庭或部分占床；
  房间剩余床位必须不小于家庭人数，家庭中有成员需要无障碍设施时房间必须支持无障碍。
- **房间选择**：在满足容量和无障碍条件的房间中，按“剩余床位最少、房间编号最小”稳定选择。
- **唯一约束**：家庭号全局唯一，成员身份标识全局唯一；家庭已存在有效入住时整笔拒绝新的入住。
- **幂等**：入住和转移请求必须携带幂等键。相同幂等键 + 相同内容的重放返回首次结果；
  相同幂等键 + 不同内容返回 `409 IDEMPOTENCY_CONFLICT`。
- **并发安全**：入住对家庭行和候选房间行加悲观写锁（`SELECT ... FOR UPDATE`）并复核剩余床位，
  并发入住不会超卖房间。
- **整体转移**：转移在同一事务内先锁定目标安置点的合适房间，再释放原房间；
  目标安置点没有合适房间时整个事务回滚，原入住完整保留。
  请求需携带 `expectedStayId` 防止基于陈旧状态转移；两个并发转移只有一个能成功，
  不会重复释放床位或形成双重入住。
- **退住**：退住在同一事务内结束有效入住并释放床位，追加 `CHECK_OUT` 事件；
  需携带 `expectedStayId`，幂等重放不会重复释放床位。
- **临时入住**：走散成员可以单人临时家庭（`TMP-<身份标识>`）入住，必须声明原家庭号；
  临时成员身份核验状态初始为 `UNVERIFIED`，正式家庭成员登记时即为 `VERIFIED`。
- **身份核验**：核验事件只增不改、按幂等键去重；核验通过后成员置为 `VERIFIED`。
  未完成身份核验的临时成员不能被并入正式家庭（`409 UNVERIFIED_MEMBER`）。
- **安全合并**：合并申请把多个临时入住并入一个正式家庭。确认时按家庭号字典序锁定全部
  涉及家庭，重新检查成员唯一性、全部临时成员已核验、目标房间容量与无障碍条件；
  任一条件不满足则整体回滚，原入住保持不变。全部满足时一次性迁移全部成员：
  原房间住得下就原地并入，住不下或为合并指定了 `targetShelterId` 时，在同一事务内
  为全家另选房间（临时成员即将腾出的床位计入有效剩余）。合并业务号幂等，
  重放返回首次结果，不会重复迁移成员或重复释放床位。
- **并发一致性**：合并、转移、退住共享同一把家庭行锁与房间行锁，并发操作串行化，
  不会产生重复成员、双重入住或错误释放床位。
- **事件流**：每次入住、转移、合并、退住追加一条不可变事件
  （`CHECK_IN` / `TRANSFER` / `MERGE` / `CHECK_OUT`），只增不改。
  合并时目标家庭与每个临时家庭各追加一条 `MERGE`，临时入住记录保留为已结束状态，
  查询可还原成员身份确认、家庭关系变化及完整房间迁移链。
- **统一错误**：所有错误返回 `{"code", "message", "timestamp"}` 结构的 JSON。

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/shelters` | 创建安置点 |
| POST | `/api/shelters/{id}/rooms` | 为安置点添加房间（床位数、无障碍标记） |
| GET | `/api/shelters/{id}/rooms` | 查询安置点各房间占用 |
| POST | `/api/households` | 登记家庭及成员 |
| GET | `/api/households/{no}/stay` | 查询家庭当前有效入住 |
| GET | `/api/households/{no}/events` | 查询家庭入住/转移/合并/退住事件流 |
| GET | `/api/households/{no}/members` | 查询家庭成员（含核验状态、声明的原家庭号） |
| POST | `/api/check-ins` | 家庭整体入住（幂等键 + 家庭号 + 安置点） |
| POST | `/api/transfers` | 家庭整体转移（幂等键 + 目标安置点 + 期望入住 ID） |
| POST | `/api/check-outs` | 退住（幂等键 + 家庭号 + 期望入住 ID） |
| POST | `/api/temporary-check-ins` | 走散成员临时入住（幂等键 + 身份标识 + 声明的原家庭号 + 安置点） |
| POST | `/api/identity-verifications` | 记录身份核验事件（幂等键 + 身份标识） |
| GET | `/api/members/{identityNo}/verifications` | 查询成员身份核验事件 |
| POST | `/api/merges` | 合并临时入住到正式家庭（合并业务号 + 目标家庭号 + 临时家庭号列表 + 可选目标安置点） |

## 开发环境

- JDK 21
- Spring Boot 4.1.1
- Maven Wrapper 3.9.9
- H2

## 本地运行

启动服务：

    ./mvnw spring-boot:run

运行测试：

    ./mvnw clean test
